# Jiza wordmark concepts

Created using the built-in image-generation tool. These are transparent PNG wordmarks, not installable font files. Flat cobalt is intended for small app headers; the glass version pairs with the existing app icons. The app UI has not been changed by this design task.

## Glass prompt
Use case: logo-brand. Create a bespoke typographic wordmark for the iPhone app jiza, which combines music, video, browsing and trading. Reference image is ONLY the established brand's cobalt colour and two softly bevelled doorway shapes; do not reproduce the icon or add it next to the text. Primary subject: exact lowercase word "jiza", spelled j i z a, one single horizontal wordmark, no other text. Design original premium geometric rounded sans-serif lettering: substantial medium-bold strokes, clean open counters, beautifully balanced tight optical spacing, distinctive curved descender on j, precise separate dots above both j and i, a softly angular z suggesting forward motion, and a single-storey a with a generous doorway-like counter. Make the dots subtle rounded slanted lozenges echoing the doorway panels. All four letters must read immediately at app-header size. Calm, sophisticated and friendly, like a beautifully crafted native media app, not gaming or graffiti. Cobalt #315BEB main letter bodies, restrained lighter blue bevel highlights that echo frosted glass while retaining a crisp solid readable silhouette. Very subtle depth only, no drop shadow outside letters. Front-facing typography, no perspective tilt, no italic slant. Wide horizontal composition, wordmark centered and filling most of width with safe margins. Transparent background, preserve real alpha, no background panel or checkerboard, no icon, no tagline, no decorative objects, no mockup, no watermarks.

## Flat prompt
Edit this exact lowercase jiza wordmark into its clean flat app-header master. Preserve the existing letter silhouettes, rounded geometry, j descender, two slanted rounded doorway-shaped dots, single-storey a, proportions and optical spacing. Change ONLY the material/finish: all letters and dots must be perfectly uniform solid cobalt #315BEB, completely opaque within shapes, crisp smooth anti-aliased vector-like edges. Remove ALL 3D, gradients, highlights, bevels, shadows, glows, grain, stray speckles and any artifacts outside the letters. Actual transparent background with clean alpha, no panel or ground. The only visible objects are the four lowercase letters j i z a and their dots. One word on one line, wide horizontal canvas, safe modest margins. This is a polished typographic logo for a native iPhone media and browser app, intended to be very legible at small header sizes.


The app now uses the flat master as a SwiftUI template image rendered in white, on cobalt for contrast in both appearances. Home and Music headers share JizaWordmark. The original master is preserved.
