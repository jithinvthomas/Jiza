Jiza Download Manager
How it works What it downloads Install

No connection waits for the last megabyte.

Jiza splits every file into lanes and downloads them over 16 connections at once. When a connection finishes its lane, it takes half of the slowest one, so the end of a download moves as fast as the start.

Built from the Jiza app's downloader

The naming rules, the list of file types worth catching, and pause, resume and retry all come from the Jiza iPhone app. The Windows version adds what a desktop download manager needs.

Every lane is remembered on disk. Close Jiza in the middle of a 5 GB file, reopen it tomorrow, and it asks the server only for the bytes it doesn't have. If a server allows fewer connections, Jiza keeps the ones it gets instead of failing.

Paste any link

Jiza looks at the address and the server's answer, then picks the right way to fetch it. Copy a link anywhere and Jiza offers to download it.

https://cdn.example.com/setup.exeFiles over HTTP or HTTPS, split across up to 32 connections.
ftp://mirror.example.org/pub/disk.isoFTP and FTPS, with resume.
https://stream.example.com/live/index.m3u8HLS streams: segments fetched in parallel, AES-128 decrypted, joined into one video.
https://www.youtube.com/watch?v=…Video pages on more than 1,000 sites, with a quality picker.
magnet:?xt=urn:btih:…Torrents and .torrent files, with DHT and peer exchange.

Install

  1. Run JizaDM.exe One 73 MB file with nothing else to install. On first start it connects itself to Chrome, Edge and Brave for your Windows account.
  2. Open chrome://extensions and turn on Developer mode In Edge, the page is edge://extensions.
  3. Click Load unpacked and choose this folder
    %AppData%\JizaDM\extension
  4. Download something Click any file link. Jiza opens with the name, size and folder already filled in. Over a video, use the Download with Jiza button.

Streams protected by DRM, such as Netflix, Disney+ and Spotify, can't be downloaded. Only download files you have the right to keep.

Jiza Download Manager 1.0 for Windows 10 and 11. Light, dark or Follow Windows under Options.
