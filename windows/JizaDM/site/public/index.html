Free download manager for Windows

No connection waits for the last megabyte.

Jiza splits every file into lanes and downloads them over 16 connections at once. When a connection finishes its lane, it takes half of the slowest one, so the end of a download moves as fast as the start.

Everything a download manager should do

Built on the downloader from the Jiza iPhone app, then extended for the desktop.

16 connections

Faster big files

Each file is split across up to 32 connections. Servers that cap connections per user are handled automatically.

Resume

Pick up where you stopped

Pause, close Jiza or restart Windows. Jiza fetches only the parts it doesn't have yet.

Browser

Takes over browser downloads

Works with Chrome, Edge and Brave. Your sign-in carries over, so downloads that need a login work too.

Video

Videos from 1,000+ sites

A Download with Jiza button appears over videos. Choose the quality, or keep just the audio.

Torrents

Magnets and .torrent files

Paste a magnet link or open a .torrent file. Jiza finds peers and checks every piece.

Scheduler

Download overnight

Start the queue at a set time, cap the speed, then let Jiza put the PC to sleep when it's done.

Install in two minutes

No installer and no account. Settings and history stay on your PC.

  1. Download and run JizaDM.exe

    Save it anywhere, such as your Desktop, and double-click it. On first start you accept the free license, and Jiza connects itself to your browsers.

  2. Open your browser's extensions page

    Go to chrome://extensions (Edge: edge://extensions) and turn on Developer mode.

  3. Load the Jiza extension

    Click Load unpacked and choose this folder:

    %AppData%\JizaDM\extension

  4. Download something

    Click any file link. Jiza opens with the name, size and folder filled in. Over a video, use the Download with Jiza button.

If Windows shows "Windows protected your PC": Jiza is new and not yet code-signed, so SmartScreen doesn't recognise it. Choose More info, then Run anyway. You can check the file first against the SHA-256 shown below.

Questions

Is Jiza really free?

Yes. You can use it on any number of PCs, at home or at work, at no cost. There are no ads, no trial period and no paid tier. The license covers the details.

Does Jiza collect any data?

No. There are no analytics. Jiza only contacts the sites you download from, the yt-dlp and FFmpeg releases on GitHub when you first use video features, and torrent peers when you download a torrent.

How do I know the file is genuine?

Compare its SHA-256 with the one on this page. In PowerShell, run Get-FileHash JizaDM.exe in the folder you saved it to.

What can't it download?

Streams protected by DRM, such as Netflix, Disney+ and Spotify. Jiza doesn't bypass copy protection. Only download files you have the right to keep.

Does it work with Firefox?

Not yet. The browser extension supports Chrome, Edge, Brave and Vivaldi. In any browser you can still copy a link; Jiza notices it and offers to download.

How do I remove it?

Close Jiza from its tray icon, delete JizaDM.exe, and delete the folder %AppData%\JizaDM. Remove the extension from your browser's extensions page.
