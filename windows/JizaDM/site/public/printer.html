How to use Jiza Printer

Seven short steps, from download to the last page. You only need steps 1 to 3 once on each PC.

  1. Download the app

    Go to jiza.app/printer and press Download for Windows. Your browser saves JizaPrinter.exe, usually in your Downloads folder.

    Move it to a folder you'll keep, for example Documents or your Desktop, before you open it. The Send to shortcut points to wherever the exe is.

  2. Open it the first time

    Double-click JizaPrinter.exe. There's no installer. The window opens in a few seconds.

    If Windows shows "Windows protected your PC": Jiza Printer is new and not yet code-signed, so Microsoft SmartScreen doesn't recognise it yet. Click More info, then Run anyway. You only see this once. To check the file is genuine first, compare its SHA-256 with the one on jiza.app/printer.

  3. Choose a printer and lock it

    In box 1, open the list and pick the printer you want, for example your office printer. The dot under it shows whether it's Ready, offline or out of paper.

    Press Lock printer. The box turns amber and says LOCKED PRINTER. From now on every file prints there, even after you close and reopen the app.

    To change printer later, press Unlock, pick another one and lock it again.

  4. Set the print options

    • Copies: use − and + (1 to 99 copies of each file).
    • Sides: Printer default, 1-sided, or 2-sided (long edge for normal documents, short edge for flip-up pages).
    • Colour: Printer default, Colour, or Black & white to save colour ink.
    • Fit to page: ticked shrinks or grows each page to fit the paper. Unticked prints at actual size.
    • Print new files as soon as they're added: tick this to print the moment a file arrives, without pressing Print.

    The app remembers your choices for next time.

  5. Add the files to print

    Use whichever way is easiest:

    • Add files (or Ctrl+O): pick one or many files.
    • Add folder: adds every printable file in a folder and its subfolders, in name order.
    • Drag and drop files or folders from Explorer onto the window.
    • From Explorer: select files, right-click, choose Send to → Jiza Printer. This needs Show in Explorer's Send to menu ticked, at the top right of the window. On Windows 11, click Show more options first.

    Each file appears in the list as Waiting, with its type and size. Select a row and press Remove to take it out, or Clear all to start again.

  6. Press Print

    The big button at the bottom says how many files will print, for example Print 5 files. Press it, or press Ctrl+P.

    Files print one after another, and each row changes to:

    • Printed: sent to the printer.
    • Sent to app: a Word, Excel or PowerPoint file was handed to that program to print.
    • Failed: something went wrong. The reason is shown, and the other files keep printing.

    To stop part-way, press Stop after this file.

  7. Tidy up

    • Retry failed: puts failed files back in the queue after you fix the problem, such as adding paper.
    • Clear printed: removes finished files and keeps the rest.
    • Close the window when you're done. The locked printer and options are saved for next time.

What it can print

Jiza Printer picks the right way to print each file for you.

File typeHow it prints
PDF, XPS, EPUB, MOBI, comic books (CBZ, CBR), DjVu, CHMPrinted directly by Jiza Printer's built-in engine. No other program needed.
Photos: JPG, PNG, GIF, BMP, TIFF (every page), WebPPrinted directly, one picture per page. Wide pictures print on landscape paper.
Text: TXT, CSV, LOG, JSON, XML and code filesPrinted directly in a clear fixed-width font.
Word, Excel, PowerPoint, RTF, ODT, HTMLHanded to the program installed for that file, such as Microsoft Word, to print. That program must be installed. For these files, 2-sided and colour come from that program's own settings.

Questions and problems

A Word or Excel file says Failed

Word and Excel files print through Microsoft Office (or another program set to open them). Check that Office is installed and that the file opens normally when you double-click it. Then press Retry failed.

The printer shows offline or out of paper

Fix the printer first: turn it on, check the cable or Wi-Fi, add paper or clear the jam. Press the small refresh button next to the status to check again, then Retry failed.

I don't see Jiza Printer in Send to

Tick Show in Explorer's Send to menu at the top right of the window. On Windows 11, right-click the files and choose Show more options to see Send to. If you moved the exe, open it once from its new place so the shortcut updates.

Pages come out too small or cut off

Tick Fit to page to scale each page to the paper. Untick it to print at the file's actual size.

How do I know the download is genuine?

In the folder where you saved it, open PowerShell and run Get-FileHash JizaPrinter.exe. The result must match the SHA-256 shown at the bottom of jiza.app/printer.

How do I remove it?

Untick Show in Explorer's Send to menu, close the app, delete JizaPrinter.exe, and delete the folders %AppData%\JizaPrinter and %LocalAppData%\JizaPrinter.

Does it send any data anywhere?

No. Jiza Printer works entirely on your PC and only talks to your printers. There are no accounts, ads or analytics.
